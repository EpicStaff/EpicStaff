
================================================================
 Available commands
================================================================
 Run from the repo root. Each target uses the service's own
 src/<service>/.venv and puts the repo root on PYTHONPATH.
 The Docker stack is run with `docker compose` directly from src/.

 UV DEPENDENCY MANAGEMENT
----------------------------------------------------------------
 make uv-sync svc=<service>
   Create/refresh src/<service>/.venv from its uv.lock
   (same flags as the Docker builders).
   Example: make uv-sync svc=django_app

 make uv-lock
   Regenerate uv.lock for every backend service in src/.
   Run after editing any service's pyproject.toml dependencies.

 make uv-lock-<service>
   Regenerate the lock for one service only.
   Example: make uv-lock-crew

 LOCAL DJANGO DEVELOPMENT
----------------------------------------------------------------
 make django-tests ARGS=<pytest-args>
   Run pytest against the Django app locally. Needs Postgres.
   Example: make django-tests
   Example: make django-tests ARGS="tests/api_tests/quickstart_test.py -v"
   Example: make django-tests ARGS="tests/api_tests/quickstart_test.py::test_post_quickstart_success -v"

 make django-makemigrations ARGS=<app>
   Run makemigrations locally.
   Example: make django-makemigrations ARGS=tables

 make django-migrate ARGS=<args>
   Run migrate locally.

 make django-manage CMD=<command>
   Run any manage.py command locally.
   Example: make django-manage CMD=shell

 SERVICE TESTS
----------------------------------------------------------------
 make <service>-tests ARGS=<pytest-args>
   Run pytest for any other uv service in src/ (crew, agent,
   sandbox, knowledge_new, realtime, webhook, ...).
   Example: make crew-tests
   Example: make agent-tests ARGS="-k my_test"

 ENV FILE AND BENCHMARK
----------------------------------------------------------------
 These run on the host Python 3.11+ (PYTHON=<interpreter> to
 override), not on a service venv.

 make env-update [DEV=1]
   Append the variables src/.env lacks (from src/env.yaml);
   existing lines are never changed. DEV=1: development defaults.

 make bench-flow
   Import benchmark/flows/payload.json (the payload benchmark
   flow) and print its graph id.

 make bench-dev ARGS=<bench-dev-options>
   Developer benchmark check; see benchmark/README.md.
   Example: make bench-dev ARGS='--note "before fix"'
