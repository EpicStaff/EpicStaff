# PLUGINS_HOST_TEMPLATE cases every validator must agree on: django_app's
# plugins.configuration.host_template (tests/plugins_tests/test_plugins_system_checks.py),
# scripts/envtool.py (scripts/test_envtool.py) and nginx's
# 16-normalize-plugins-enabled.envsh (src/nginx/tests/check_templates.sh).
#
# One case per line: `accept <template>` or `refuse <rule> <template>`. <rule> names the rule
# the template breaks, for the suites that check the message: placement, parent, affix,
# label-length, host-length, reserved or placeholder. `<empty>` stands for an empty value.
# Templates are written exactly as entered: case and a trailing dot, which envtool's wizard
# normalises, are covered by each suite's own tests.
#
# Every template here is judged with EpicStaff at https://epicstaff.example.com: an accepted
# one is the same site and never names EpicStaff's own host.

accept app-{id}.example.com
accept {id}.plugins.example.com
accept ab{id}.example.com
accept abc-{id}.example.com
accept abc--{id}.example.com
accept {id}-a--b.example.com
accept {id}0.example.com
accept {id}-aaaaaaaaaaaaaaaaaaaaaaaaaaaaaa.example.com
accept {id}.aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa.aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa.aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa.bbbbbbbbbbbbbbbb.example.com
refuse placement <empty>

refuse placement app.{id}.example.com

refuse affix {id}-.example.com
